# Asset sources

- Movie posters and Interstellar backdrop: [TMDB](https://www.themoviedb.org/), served from `image.tmdb.org` using the paths stored in the catalog. Not downloaded movie videos.
- `tmdb-logo.svg`: official TMDB logo downloaded from [TMDB branding page](https://www.themoviedb.org/about/logos-attribution), file `blue_long_2-9665a76b1ae401a510ec1e0ca40ddcb3b0cfe45f1d51b77a308fea0845885648.svg` on TMDB's asset server.
- `poster-placeholder.svg`: original simple placeholder created for this project.
- Demo movie descriptions: original Vietnamese summaries for development. Demo scores and release years are not a live TMDB feed.
